# Distributed Ray Trace backend 1.0.0

CPU physically based path tracing and authenticated compute-node support. The Windows desktop includes its integrated backend. The independently distributed backend is for Linux x86_64 only.

The release User Guide explains configuration and pairing. Run `drt-agent --help`, `drt-agent agent --help` and `drt-agent doctor --json` for supported commands. Product version 1.0.0 is separate from frontend protocol 5 and Worker wire 4.
